\subsection{Reproduction}
\label{app:reproduction}

Runs used OG-Core \genOgcoreVersion{} with \texttt{patches/ogcore-0.17.0-firm-gamma-tv.diff} applied to the installed package, OG-UK at commit \genOgukSha{}, PolicyEngine \genPolicyengineVersion{}, PolicyEngine UK \genPolicyengineUkVersion{} and Python \genPythonVersion{}; the committed results were produced on \genRunDate{}. OG-UK's calibration reads PolicyEngine's UK data from Hugging Face, so a re-run requires a token. From the repository root:

\begin{verbatim}
python -m uk_growth_with_ai run --baseline-only --out results/baseline.json
python -m uk_growth_with_ai check --results results/baseline.json
python -m uk_growth_with_ai run --out results/scenarios.json
python -m uk_growth_with_ai run --baseline-spending \
       --out results/scenarios_fixed_spending.json
python -m uk_growth_with_ai check --results results/scenarios.json
python paper/make_values.py          # regenerates paper/values_generated.tex
pdflatex main && pdflatex main       # in paper/
\end{verbatim}

Every number in this paper is a macro in \texttt{paper/values\_generated.tex}, generated by \texttt{paper/make\_values.py} from the committed results files and from the published OBR and Table~3 figures recorded in \texttt{uk\_growth\_with\_ai/obr.py} and \texttt{uk\_growth\_with\_ai/scenarios.py}. \texttt{python paper/make\_values.py --check} exits non-zero if the generated file is stale, and \texttt{\textbackslash GENMISSING} marks any macro whose source was absent at generation time, which makes the LaTeX build fail rather than silently omitting a number.
